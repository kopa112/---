<h1>Курсовой проект</h1>
<h3>по теме: База данных "Игры симуляторы"</h3>

<h2>1. Постановка задачи</h2>
Разработать консольное приложение для управления файловой базой данных игр-симуляторов с возможностями:

- Хранения информации о симуляторах (название, разработчик, издатель, год выпуска, тип, сложность, оценка физики, количество миссий)

- Загрузки и сохранения данных в текстовых файлах

- Добавления новых записей с валидацией ввода

- Сортировки по комбинации критериев (название → тип → сложность)

- Поиска записей по типу или комбинации издатель+сложность

- Отображения данных в табличном формате

<h2>3. Ключевые функции</h2>
<h3>Основные функции управления</h3>
<code>main()</code>

- Назначение: Точка входа программы, управление основным потоком выполнения

- Особенности: Автоматическая загрузка данных при запуске, обработка пользовательского меню

<code>printTable(Simulator* a, int n)</code>
- Назначение: Красивый табличный вывод

- Формат: Нумерованные строки, выравненные столбцы

- Обработка: Сообщение при пустом массиве

<code>loadFromFile(char* fname, Simulator* a, int max)</code>
- Назначение: Загрузка данных из CSV-файла

- Обработка ошибок: Проверка каждой строки, подсчет успешных записей

<code>saveToFile(char* fname, Simulator* a, int n)</code>
- Назначение: Сохранение массива в файл
  
- Особенности: Сохраняет в том же формате, проверяет запись каждой строки

<code>addSimToArray(Simulator* a, int* n, int max)</code>
- Назначение: Интерактивное добавление новой записи

- Валидация: Год (1980-2030), физика (0-10), миссии (≥0)

- Ввод: Пошаговый с проверкой каждого поля

<code>saveArrayToFile(Simulator* a, int n)</code>
- Назначение: Сохранение всего массива

- Особенности: Запрашивает имя файла, вызывает <code>saveToFile</code>

<code>sortByTitleTypeDiff(Simulator* a, int n)</code>
- Назначение: Трехуровневая сортировка

- Порядок: 1. Название → 2. Тип → 3. Сложность

- Алгоритм: Сортировка вставками с составным ключом сравнения

<code>searchByType(Simulator* a, int n, SimType type)</code>
- Назначение: Поиск игр по типу симулятора

- Типы: Авиа, авто, космос, ж/д, военные, другие

- Вывод: Таблица с результатами

<code>searchByPublisherAndDiff(Simulator* a, int n, char* publisher, Difficulty diff)</code>
- Назначение: Комбинированный поиск

- Реализация: Линейный поиск с двумя условиями фильтрации

- Вывод: Табличное отображение с указанием критериев поиска

<h2>5. Формат данных</h2>
<h3>Перечисления (Enums)</h3>

- Типы симуляторов:

<code>typedef enum {
    FLIGHT_SIM,      
    DRIVING_SIM,     
    SPACE_SIM,       
    TRAIN_SIM,       
    MILITARY_SIM,    
    OTHER_SIM        
} SimType;</code>

- Уровни сложности:

<code>BEGINNER       
INTERMEDIATE   
ADVANCED       
EXPERT</code>     

<h3>Основная структура <code>Simulator</code></h3>

<code>typedef struct {
    char title[40];        
    char developer[40];    
    char publisher[40];   
    int year;             
    SimType type;         
    Difficulty difficulty; 
    float physics;       
    int missions;         
} Simulator;</code>

<h2>Формат файлов данных</h2>

<h3>Текстовый формат (.txt)</h3>

- Структура строки

  Название;Разработчик;Издатель;Год;Тип;Сложность;Физика;Миссии

- Пример файла

  MS_Flight_Simulator_2020;Asobo_Studio;Microsoft;2020;Авиасимулятор;Средний;8,5;30
  Assetto_Corsa;Kunos_Simulazioni;505_Games;2014;Автосимулятор;Продвинутый;9,0;15
  Kerbal_Space_Program;Squad;Private_Division;2015;Космический;Начинающий;7,5;50
  Train_Sim_World_3;Dovetail_Games;Dovetail_Games;2022;Железнодорожный;Средний;8,0;25
  DCS_World;Eagle_Dynamics;Eagle_Dynamics;2008;Военный;Эксперт;9,5;100

<h3>Правила записи:</h3>

1. Разделитель: Точка с запятой (;)

2. Текст: Русские слова для типа и сложности

3. Числа: Целые для года и миссий, десятичные для физики

4. Пробелы: Использовать <code>_</code> вместо пробелов

<h3>Ограничения:</h3>

- Максимум 100 записей в массиве

- Текстовые поля: до 39 символов

- Год выпуска: 1980-2030

- Физика: от 0,0 до 10,0

- Миссии: неотрицательное число
